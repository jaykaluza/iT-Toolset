First time on this PC? Set it up
Starting NetMonitor… If the Microsoft Store opened instead, NetMonitor isn't set up on this PC yet: close the Store and click here to show the setup steps.
Set up on this PC (one time):
  1. Download NetMonitor.exe and save it in a folder of its own (for example Documents\NetMonitor). Don't open it straight from your browser's download bar: that runs it from a temporary folder the browser deletes later, and RUN would stop working.
  2. Check it's genuine: compare Get-FileHash .\NetMonitor.exe with the fingerprint on the release page.
  3. Double-click it once and click Yes. That sets up the RUN button on this PC.
  4. Then click the button below. Your browser will ask to open the app: click Open (tick "always allow" to skip this next time). From then on, RUN starts it directly.
