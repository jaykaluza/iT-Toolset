My Connections

First time on this PC? Two steps:

  1. Download MyConnections.exe and save it somewhere you'll keep, such as Documents.
  2. Double-click it and click Yes. If Windows warns you, click More info, then Run anyway.

This window closes by itself when the app starts, and RUN works from then on. If your browser asks to connect to apps on this device, choose Allow.

Check it's genuine: compare Get-FileHash .\MyConnections.exeHow to check, step by step:1. In File Explorer, open the folder where you saved MyConnections.exe.2. Click the address bar at the top of that window, type powershell.exe and press Enter. A PowerShell window opens in that folder.3. Type or paste Get-FileHash .\MyConnections.exe and press Enter.4. Open the release page and find the fingerprint under Check it's genuine.5. Compare it with the long line of letters and numbers next to Hash. They must match exactly. If they don't, don't run the file. with the fingerprint on the release page.
