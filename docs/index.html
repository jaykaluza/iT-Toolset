Windows Network Traffic Monitor

See every connection your PC makes and the app behind it, spot risky apps, and end or block them.
First time on this PC? Set it up
Didn't start? The app needs a one-time setup on each PC:
  1. Download NetMonitor.exe and save it in a folder of its own (for example Documents\NetMonitor).
  2. Check it's genuine: compare Get-FileHash .\NetMonitor.exe with the fingerprint on the release page.
  3. Double-click it once and click Yes. That sets up the RUN button on this PC.
  4. Come back and click RUN. Your browser will ask to open the app: click Open (tick "always allow" to skip this next time).

To remove the RUN button link later, run NetMonitor.exe --unregister-link.
