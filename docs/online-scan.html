Public address

Shows the internet address websites see for you, and whether it looks like a home or mobile connection. This sends one request to api.ipify.org, so it runs only if you press the button.

What a web page cannot check

Browsers deliberately keep websites away from your PC. For these you need the Full scan, which runs as a Windows app:

  • Open ports and the programs behind them
  • Running programs and where they connect
  • Firewall rules and Defender status
  • Windows patches and risky settings
  • Malware signs and hacker tools
  • User accounts, shares and services
  • Fixes you can apply and undo
  • Live monitoring of threats
